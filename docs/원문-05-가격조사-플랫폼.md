## ⚠️ 접근 한계 (정직한 보고)

- **배달의민족 / 쿠팡이츠 / 요기요** 의 실시간 메뉴판은 로그인·앱 내부 확인이 필요하고, 웹 스크래핑이 차단되어 있어 **라이브 메뉴별 가격을 자동 수집할 수 없었습니다.**

## 📊 핵심 인사이트

1. **원가율은 20% 안팎으로 낮음** — 족발/보쌈은 재료비가 낮아 가격(프라이싱) 여지가 큼. 즉, 25,000원 실속 메뉴에서도 남는 돈(마진)이 충분히 확보됨.
2. **가격대가 침샘족발과 정확히 겹침** — 25,000원(만수점) vs 침샘의 2~3만 원대. '가격'이 아니라 '브랜드 신뢰 + 포장 혜택'으로 승부해야 함.
3. **쟁반국수·주먹밥(3,000~8,000원)이 핵심 사이드** — 원가가 싸서 '서비스/미끼'로 주기 좋은 품목.
