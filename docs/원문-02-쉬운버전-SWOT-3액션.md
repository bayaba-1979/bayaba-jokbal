# [원문 2] 사장님 귀에 쏙 들어오는 쉬운 버전 — SWOT + 3가지 액션

어려운 마케팅 용어 다 빼고, 인천 만수동에서 장사하시는 사장님 귀에 쏙 들어오게 아주 쉽게 딱 정리해 드릴게요.

저놈들(침샘족발)이 도대체 뭘 잘해서 내 손님을 채간 건지, 우리는 그동안 뭘 놓치고 있었는지, 그리고 당장 어떻게 뒤집어야 하는지 SWOT 분석과 핵심 솔루션으로 보여드립니다.

## 🥊 1. 저놈들(침샘족발)이 잘한 것 vs 우리가 못 한 것 (한눈에 보기)

### 저놈들이 잘한 것 (이유)

- **손님 지갑 열기 쉬운 '미끼'를 던졌음:** 족발 하면 "대·중·소 시키면 4만 원 넘지"라는 부담이 있는데, 1+1이나 2~3만 원대 실속 메뉴를 깔아놔서 앱에서 구경하던 손님이 부담 없이 장바구니에 쏙 담게 만듦.
- **남들 잘 때 문 열었음:** 밤 10시 넘어서 야식 먹으려 할 때 선택지가 없으니까, 24시간 심야 영업으로 밤늦은 수요를 혼자서 다 독식함.
- **배달비 아끼는 법을 알았음:** 포장해 가면 8,000원을 깎아주니까, "어차피 집 앞인데 내가 가지 뭐" 하는 동네 손님들을 매장으로 싹 쓸어 모음.

### 우리가 못 한 것 (이유)

- **"우린 대기업 브랜드야" 하고 점잖 빼고 있었음:** 가맛족 간판 달고 정가(비싼 가격)만 고수하다 보니, 배달앱에서 가성비 찾는 젊은 층 눈에는 "저 집은 비싸서 패스" 하고 걸러지는 타겟이 되어 버림.
- **배달 플랫폼에 내 돈 다 뜯겼음:** 홀 장사도 하면서 배달도 같이 돌렸지만, 배달앱 수수료(10~15%)랑 배달대행비로 나가는 돈이 얼만데 앱 가격을 매장 가격이랑 똑같이 방치함.
- **손님이 오면 끝이었음:** 한 번 배달 나가거나 홀에 손님이 다녀가도, "다음엔 우리 가게로 직접 전화해" 하고 내 사람(단골)으로 만드는 락인(Lock-in) 장치를 적극적으로 안 씀.

## 📊 2. 가장맛있는족발 만수점 SWOT 분석

| 구분 | 내용 (우리 매장 기준) |
|---|---|
| S (강점 - 우리가 가진 무기) | • 동네 사람들이 다 아는 '가장맛있는족발'이라는 튼튼한 브랜드 신뢰도와 맛의 안정감<br>• 배달만 하는 허름한 곳이 아니라, 넓고 깨끗한 홀 매장을 보유하고 있음 |
| W (약점 - 우리가 고쳐야 할 것) | • 정가 위주로만 팔다 보니 배달앱에서 가성비 메뉴를 찾는 1~2인 가구/야식족을 놓치고 있음<br>• 배달앱 수수료와 대행료 구조 때문에 매출은 찍히는데 실속(마진)이 안 남을 수 있음 |
| O (기회 - 파고들 틈새) | • 만수동 주민들 중 "배달비 아깝고 집 근처인데 포장해 갈까?" 하는 방문 포장 수요가 엄청남<br>• 침샘족발이 못 잡는 가족 외식, 홀 회식, 깔끔한 매장 식사 수요를 우리가 독점 가능 |
| T (위협 - 우리를 위협하는 것) | • 침샘족발처럼 1+1, 할인 쿠폰, 심야 영업으로 무장한 전투형 브랜드가 계속 내 구역을 파고듦 |

## 🛠️ 3. [만수점 만점짜리 솔루션] 당장 내일부로 실행할 3가지 액션

이론은 끝났고, 사장님이 당장 배달앱과 매장에서 손대야 할 실전 솔루션입니다.

### ① [배달앱 개조] 2~3만 원대 '미끼 메뉴' 강제 신설

- **할 일:** 앱 메뉴판 맨 위에 [1인·혼술 실속 족발 도시락 (29,000원)] 또는 [미니족 + 주먹밥 콤보 (26,000원)]를 당장 만드세요.
- **이유:** 저놈들이 1+1이나 저렴한 구성으로 채가던 1인 가구, 야식 손님의 장바구니를 우리도 똑같이 낚아채기 위해서입니다. 정가 4만 원짜리만 놔두면 손님은 아예 들어오지도 않습니다.

### ② [포장 판촉 역공] 배달비·수수료 아낀 돈을 손님에게 던져주기

- **할 일:** 가게 앞에 대문짝만하게, 그리고 배달앱 배너에 "방문 포장 시 즉시 4,000원 할인 + 대형 막국수 서비스 (배달비 0원)"를 걸어두세요.
- **이유:** 배달로 나가면 플랫폼에 수수료 뜯기고 대행비 내느니, 그 돈의 일부를 포장해 가는 손님한테 쥐여주면 손님은 "여기가 훨씬 이득이네!" 하고 오고, 사장님은 수수료를 아껴서 마진을 지킵니다.

### ③ [단골 내재화] 배달 박스마다 '직주문 쿠폰' 심기

- **할 일:** 배달 나가는 모든 용기 위에 자석 스티커나 쿠폰을 붙이세요. "만수동 주민 여러분, 앱 쓰지 마시고 매장으로 직접 전화 주시면 매번 5,000원 상당의 사이드를 더 챙겨드립니다."
- **이유:** 플랫폼 수수료로 새나가는 돈을 막고, 한 번 온 손님이 다음에는 무조건 사장님 번호로 전화하게 만드는 진짜 내 단골을 만들기 위해서입니다.
